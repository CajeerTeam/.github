# Community

Cajeer uses different platforms for different kinds of signal.  
The voice stays the same across all of them: calm, technical, exact, and low-noise.

## Website

**https://cajeer.com/**

The shortest public introduction to the team, the position, and the direction.

## GitBook

**https://docs.cajeer.com/**

The canonical documentation layer: principles, structure, project direction, and implementation-facing material.

## GitHub

**https://github.com/CajeerTeam**

Source, releases, issues, code history, and contribution context.

## Telegram channel

**https://t.me/cajeer**

Broadcast surface for releases, announcements, notes, and links.

## Telegram chat

**https://t.me/cjrmeet**

Reply layer for discussion around announcements, releases, and public notes.

## Discord

**https://discord.gg/nsTKEUh2DB**

Longer engineering discussion, support, showcases, contributor interaction, and release follow-up.

## Community posture

- keep noise low
- keep updates readable
- keep support contextual
- keep technical discussions searchable
- keep hype below the signal level
