# GitBook setup

Use this page to keep GitBook visually aligned with the website and README.

## Core settings

### Title
`Cajeer Docs`

### Icon
Upload `assets/cajeer-avatar.png`

### Logo
- dark mode: `assets/cajeer-mark-dark.png`
- light mode: `assets/cajeer-mark-light.png`

If custom logos are not available on your GitBook plan, keep the icon and title visible and use the theme settings below.

## Theme

Start with **Muted** or **Clean**.

- **Primary color:** `#5B8CFF`
- **Tint color:** `#EEF4FF` or a nearby cold tint

## Header links

- Website → `https://cajeer.com/`
- GitHub → `https://github.com/CajeerTeam`
- Telegram → `https://t.me/cajeer`
- Discord → `https://discord.gg/nsTKEUh2DB`

## Primary link

Set the logo click target to:

`https://cajeer.com/`

## Footer

## Important limitation

GitBook branding is configured in the GitBook customization UI.  
Use the repository for content, shared assets, and consistent copy — not for custom CSS or JavaScript.

## Check result

GitBook should feel like a continuation of the main site:

- the same dark, restrained tone
- the same cold blue accent
- the same link order
- the same split between Cajeer Team and Cajeer 404
