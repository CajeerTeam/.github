# Brand system

## Core language

### Primary signal
`Open-source systems. Quiet by design.`

### Secondary signal
`Built with discipline. Shipped without theater.`

### Position
Cajeer builds open-source software, developer tools, and focused infrastructure.  
Cajeer 404 is the public edge — releases, notes, experiments, and community.

## Visual system

### Palette

| Token | Value | Role |
| --- | --- | --- |
| Background | `#0A0F17` | main site and docs background |
| Soft background | `#101823` | panels and secondary surfaces |
| Panel | `#111B27` | cards and overlays |
| Text | `#EEF4FF` | primary text |
| Muted | `#9AA8BD` | secondary text |
| Muted-2 | `#6F7D91` | labels and metadata |
| Accent | `#5B8CFF` | links, buttons, focus areas |
| Accent soft | `#8CB1FF` | secondary highlights |

### Typography

- **Primary:** Inter or system UI sans-serif
- **Technical labels:** monospace
- **Headline posture:** few words, large size, strong spacing
- **Body posture:** direct, compact, readable

### Shape language

- dark surfaces
- thin borders
- generous spacing
- rounded panels
- cold glow used sparingly

## Tone of voice

### Use this tone
- exact
- calm
- technical
- selective
- builder-first

### Avoid this tone
- loud
- ironic-forced
- vague
- overpromotional
- emoji-heavy

## Structural split

### Cajeer Team
The official contour: products, standards, architecture, long-term direction.

### Cajeer 404
The public edge: releases, notes, experiments, community signal.

## Do / don't

### Do
- write short headlines
- prefer nouns over slogans
- show fewer things, more clearly
- keep release copy plain and factual
- make documentation feel first-class

### Don't
- overload pages with gradients, stickers, or badges
- use hype as a substitute for clarity
- mix playful community tone with formal technical copy
- bury core links behind visual clutter
